🛒 Nexa Mart – Full Stack E-Commerce Application
📌 Project Overview

Nexa Mart is a full-stack multi-vendor e-commerce platform designed to provide a smooth shopping experience for users and powerful management tools for sellers and admins.
The application follows mvc architecture principles, ensuring scalability, security, and performance.

🧰 Tech Stack
🔙 Backend

1) Java 17
2) Spring Boot
3) Spring Security
4) Spring Data JPA
5) Swagger
6) Spring Mvc
7) JWT Authentication
8) MySQL
9) RESTful APIs
10) Sream Api
11) Java 8

This project demonstrates my practical knowledge of Java, Spring Boot, Microservices, REST APIs, Authentication, and Frontend integration.

🚀 Key Features

👤 User Features

1) User registration & login (JWT-based authentication)

2) Browse products by category

3) Product search & filtering

4) Add to cart & wishlist

5) Place orders & view order history

6) Secure online payments (Razorpay / Stripe)

7) Product reviews & ratings

🛒 Seller Features

1) Seller registration & login

2) Add / update / delete products

3) Manage inventory

4) View orders & sales analytics

🛠️ Admin Features

1) Admin dashboard

2) Manage users, sellers & products

3) Order monitoring

4) Platform-level control

🔐 Security Features

1) JWT Authentication

2) Role-based access control (ADMIN / SELLER / USER)

3) Secure API access using Spring Security
